TrueLine — Product Requirements (v1) One line: Voice-calling app where users pay per minute to talk to verified listeners ("partners"). India market, Hindi first. iOS + Android. 1. What we're building Two apps (or one app with two modes): 1. User app — browse partners, recharge wallet, make calls, chat 2. Partner app — go online/offline, receive calls, track earnings, withdraw Not in v1: video calls, group calls, gifting, games, multiple user tiers, iOS-specific features. Keep it lean. 2. Core flows User side Onboarding - Phone number + OTP login (no email, no password) - Language selection (Hindi at launch; UI ready for more) - Land on Discover screen Discover (home) - List of partners: photo/avatar, name, verified tick, rating, language, price/min - Online partners on top (green dot), offline greyed out below - Language filter chips - Tap call button → call starts if balance is sufficient, else → recharge screen Wallet - Coin balance always visible in header - Recharge packs (3 options), UPI via payment aggregator (Razorpay/Cashfree) - Coins map to talk-time; pricing: ₹9/min (1 coin ≈ ₹1 for simplicity — confirm) - Transaction history Calling - In-app VoIP only (100ms or ZegoCloud SDK). No phone numbers exchanged, ever. - Per-minute billing: deduct from wallet as call runs - In-call screen: partner name/photo, timer, balance remaining, mute, speaker, end - Lowbalance warning at 2 minutes remaining → bottom sheet with one-tap recharge, call continues during payment - Call ends automatically when balance hits zero Post-call - Rating screen (1–5 stars) - "Add to favourites" option - Favourites: user gets a push notification when a favourite partner comes online Chat - Simple text chat with partners (WhatsApp-style list + thread) - Chat is free in v1 (drives call conversion); revisit paid chat later Partner side Onboarding - Phone + OTP - Profile setup: name, photo, languages, short bio - KYC upload (ID document) → manual admin approval before going live Home - Big online/offline toggle - Today's earnings, this week, rating, call count - Recent calls list with per-call earnings Incoming call - Full-screen incoming call UI (works when app is backgrounded — needs push + CallKit/ConnectionService) - Shows caller name and per-minute earning rate - Accept / Decline Earnings - Available balance, withdraw to UPI button - Payout within 24h (manual admin approval OK for v1) - TDS deducted per applicable rules — show net amount - History of withdrawals and weekly earnings 3. Money logic (the part to get right) User pays ₹9/min. Partner earns ₹4.5/min (50/50 — confirm final split). Billing per completed minute; define rounding rule (recommend: per-second metering, charged per started minute) Dropped call (network): don't charge the incomplete minute; auto-refund edge cases Wallet is prepaid only. We never store card details — payment aggregator handles it. GST included in recharge pack pricingTDS on partner payouts built into payout flow from day one 4. Trust & safety (v1 minimum) Partners are KYC-verified before going live (manual review) Users can report/block a partner; partner can report/block a user No phone numbers visible to either side anywhere Call recording: decide before build — if yes (for dispute resolution), needs consent notice at call start; if no, skip entirely for v1 Admin panel: approve partners, view reports, suspend accounts, adjust wallets manually 5. Screens (designs already done — attached) User: Onboarding · Discover · Wallet/Recharge · In-Call · Low-Balance Sheet · Post-Call · Chat List · Profile Partner: Home/Dashboard · Incoming Call · Earnings/Withdraw Brand guide with colors, logo, and components is attached separately. Colors: primary #2D6A6B, secondary #5FA8D3, accent #F2A65A (CTAs only), dark #0F1B22, light #F4F8F9. 6. Tech notes (suggestions, not mandates) Calling: 100ms or ZegoCloud (both have prebuilt call UI kits — use them, don't build call UI from scratch) Payments: Razorpay or Cashfree (recharge) + payout API (partner withdrawals) Push: FCM + APNs; incoming calls need high-priority push + native call UI (CallKit on iOS, ConnectionService on Android) Backend: anything the team is fast in. Needs: auth, wallet ledger, call session + billing engine, partner availability state, admin panel The wallet ledger and per-minute billing engine are the highest-risk components. Every coin movement must be a ledger entry (no direct balance edits). Handle: double-charge prevention, mid-call recharge, dropped calls, concurrent calls edge case (partner can only be on one call). 7. Success criteria for v1 User can go from install → first paid call in under 3 minutes Call connects in under 10 seconds when partner accepts Zero billing disputes from rounding/drop edge cases in pilot Partner can go from approval → first earning → UPI withdrawal without contacting support
